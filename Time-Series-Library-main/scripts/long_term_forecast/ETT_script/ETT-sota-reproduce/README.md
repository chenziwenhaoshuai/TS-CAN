# ETT SOTA Reproduce

Clean entry points for the ETT best-known CANPatchTST reproduction set.

Run from `Time-Series-Library-main`:

```bash
bash scripts/long_term_forecast/ETT_script/ETT-sota-reproduce/run_ett_16_best_configs.sh
```

Additional entry points:

```bash
bash scripts/long_term_forecast/ETT_script/ETT-sota-reproduce/run_winning_artifact_configs.sh
bash scripts/long_term_forecast/ETT_script/ETT-sota-reproduce/run_etth2_current_best.sh
```

`winning_configs.csv` contains the compact result table. Full evidence, helper scripts, historical CSVs, and detailed notes are kept in `../ETT-sota-reproduce-archive/`.
