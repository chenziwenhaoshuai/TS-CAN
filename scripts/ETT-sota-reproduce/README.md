# ETT Table-12 CANPatchTST Reproduction

This folder separates four different records that were previously mixed in chat:

1. Historical table values for the 12 non-ETTh2 winning cells.
2. A fresh c209 from-scratch rerun on 2026-07-23 using the current pure CANPatchTST scripts.
3. The current best ETTh2 tuned configurations and metrics.
4. The actual historical winning artifact parameter set for H1/M1/M2 all horizons plus H2-720.
5. The current best ETTh2 96/192/336 scripts and results.

## Historical Table

The direct source for the table quoted in chat is `scripts/diagnose_etth2_gap.py`.
The same values are also stored in `server_results/etth2_gap_diagnosis.json`.
See `historical_table12_sources.csv` for one row per target cell. The stronger
source is `winning_artifact_params_from_c209.csv`, which was generated by
scanning c209 `metrics.npy` artifacts and retaining the cells that beat
TimeMixer++.

The historical non-H2 table was:

| Dataset | 96 | 192 | 336 | 720 |
|---|---:|---:|---:|---:|
| ETTh1 | 0.360641 | 0.408625 | 0.429203 | 0.448998 |
| ETTm1 | 0.285750 | 0.331659 | 0.368771 | 0.421972 |
| ETTm2 | 0.167709 | 0.227966 | 0.279530 | 0.357305 |

The complete 16-cell ETT result page is `ett_16_best_results.csv`. The target
set requested by the user is H1/M1/M2 all horizons plus H2-720.
`winning_artifact_repro_status.csv` records those 13 winning cells, their
TimeMixer++ references, and the wrapper script for each cell. All 13 historical
artifacts beat their TimeMixer++ reference by test MSE.


These scripts intentionally use per-cell parameters recovered from old
artifacts. They are not a single shared hyperparameter recipe. The old UCANP
family generally used `can_context_pyramid=0`, `can_temporal_roll=1`,
`can_use_gffng=1`, `can_drop_path=dropout`, and often `seq_len=512` with
`batch_size=2`. The ETTh1-336 and ETTh2-720 winners use later tuned current
repo settings.
